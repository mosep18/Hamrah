# همراه | راهنمای میدانی آفلاین 0.6.1

**همراه** یک PWA فارسی، راست‌چین و بدون بک‌اند است که دو بخش را در یک رابط ساده جمع می‌کند:

- **راهنمای ایمنی:** ۱۱ موضوع کاربردی از محتوای خلاصه‌شدهٔ پروژهٔ Tehran Safety؛ از آمادگی ۷۲ ساعته و تخلیه تا دود، انفجار، ارتباطات، راستی‌آزمایی خبر و کمک‌های اولیه.
- **ابزارهای کاربردی:** ۳۰ منبع برای نقشه، ارتباط، خبر، دسترسی و ابزارهای جانبی؛ شامل برتینا و وصل (Vasl.social).

نسخهٔ ۰٫۶٫۰ هویت بصری را به‌صورت یک راهنمای میدانی بازطراحی می‌کند: صفحهٔ اصلی نامتقارن، رنگ‌های کاغذی/سبز جنگلی/لیمویی/مرجانی، تصویر انتزاعی مسیر، تایپوگرافی فارسی بهینه‌تر و اجزای واکنش‌گرا. تعاملات قبلی—جست‌وجو، فیلتر، علاقه‌مندی و نمایش جزئیات—حفظ شده‌اند.

## اجرا

برای تست آفلاین و Service Worker، برنامه را از یک وب‌سرور محلی یا میزبانی HTTPS اجرا کنید؛ بازکردن مستقیم `index.html` با `file://` به‌تنهایی Service Worker را فعال نمی‌کند.

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید.

## انتشار روی GitHub Pages

1. فایل‌های این پوشه را در ریشهٔ یک مخزن GitHub قرار دهید.
2. از **Settings → Pages**، انتشار شاخهٔ `main` و پوشهٔ `/ (root)` را فعال کنید.
3. برنامه را یک‌بار آنلاین باز کنید تا پوسته و داده‌های اصلی ذخیره شوند.
4. در حالت هواپیما، صفحه را دوباره باز کنید و جست‌وجو، راهنمای ایمنی و جزئیات ابزارها را امتحان کنید.

تمام آدرس‌های داخلی نسبی هستند تا مخزن بتواند در زیردایرکتوری GitHub Pages هم منتشر شود.

## فایل‌های اصلی

- `index.html` — پوسته و ساختار صفحه
- `styles.css` — طراحی واکنش‌گرا، رنگ و پوستهٔ روشن/تیره
- `app.js` — جست‌وجو، صفحه‌ها، جزئیات، علاقه‌مندی‌ها و نصب
- `data.js` — فهرست ۳۰ ابزار و منابع
- `safety-data.js` — ۱۱ موضوع راهنمای ایمنی ذخیره‌شده به‌صورت محلی
- `sw.js` — کش پوسته، داده‌ها و آیکون‌های SVG محلی
- `manifest.webmanifest` — مشخصات PWA
- `icons/` — آیکون برنامه
- `CHANGELOG.md` — تغییرات نسخه

## تغییرات نسخهٔ ۰٫۶٫۰

- اصلاح مدخل برتینا و انتقال آن به وب‌سایت اصلی `https://www.bertina.ir/`؛ توضیح خدمات هاست، دامنه، سرور و زیرساخت بدون ادعای تأیید مستقل.
- اصلاح توضیح ZoomUsers با ذکر اینکه برای زمان اختلال بین‌المللی معرفی شده، اما در تاریخ بازبینی صفحهٔ اصلی غیرفعال نشان داده می‌شد.
- افزودن Vasl.social با وضعیت «نیازمند بررسی»؛ کارکرد و سیاست حریم خصوصی آن تأیید نشده است.
- افزودن `lastReviewed` به همهٔ ابزارها و `source` و `lastReviewed` به هر راهنمای ایمنی. این تاریخ به معنی آزمون زندهٔ همهٔ لینک‌ها یا تأیید علمی محتوای ایمنی نیست.
- جایگزینی آیکون‌های میزبانی‌شدهٔ بیرونی با SVGهای محلیِ جایگزین در `assets/tool-icons/`؛ برتینا به‌جای لوگوی تأییدنشده، نشان حرفیِ داخلی رابط می‌گیرد.
- افزودن یادداشت‌های شخصی محلی برای ابزارها و راهنماها، چک‌لیست‌های ذخیره‌شونده، امکان چاپ راهنمای بازشده، و اصلاح شمارنده‌های ناوبری.
- افزودن `CONTRIBUTING.md` و گسترش آزمون‌های ساختار داده و دارایی‌های محلی.
- بازبینی متنی چند صفحهٔ اصلی در ۲۵ اکتبر ۲۰۲۶: صفحهٔ بازیطوری در وضعیت به‌روزرسانی بود، توضیح PasteHub با همگام‌سازی آنلاین متن/فایل دقیق‌تر شد، و ZoomUsers فعلاً فعال فرض نمی‌شود. این بررسی مرورگر جای آزمون دسترسی از همهٔ شبکه‌ها یا بررسی امنیتی سرویس‌ها را نمی‌گیرد.

## نکات محتوایی و ایمنی

- در بستهٔ Tehran Safety که برای این نمونه ارائه شد، فایل‌های اصلی HTML و JavaScript وجود داشتند، اما برخی دارایی‌هایی که README اصلی به آن‌ها اشاره می‌کرد (از جمله PDF کامل و فایل‌های فونت/تصویر) در ZIP موجود نبودند. این نسخه از خلاصه‌های فارسی ۱۲ بخشِ تعبیه‌شده در `app.js` استفاده کرده، بخش زمینهٔ سیاسی/امنیتی تاریخ‌دار را کنار گذاشته و ۱۱ موضوع کاربردی را نگه داشته است.
- مطالب ایمنی عمومی‌اند و گزارش زنده، پیش‌بینی خطر یا جایگزین دستورهای امدادی محلی و توصیهٔ پزشکی نیستند. تاریخ و اعتبار اطلاعات را پیش از استفاده بررسی کنید.
- ثبت یک ابزار در فهرست به معنای تأیید امنیت، کیفیت، رسمی‌بودن یا دسترس‌پذیری آن نیست.
- آیکون‌های فهرست ابزارها SVGهای محلی و جایگزین‌اند، نه لوگوهای رسمی؛ آن‌ها برای وابستگی کمتر به میزبان‌های تصویر استفاده می‌شوند. از آیکون جایگزین نباید به‌عنوان اثبات هویت سرویس برداشت کرد.
- برای منابع خارجی، مرورگر هنگام بازکردن لینک مستقیماً با همان سرویس ارتباط برقرار می‌کند. اطلاعات حساس مانند رمز، توکن و کانفیگ خصوصی را در سرویس‌های ناشناس وارد نکنید.
- هیچ حساب کاربری، تبلیغات، تحلیل‌گر آماری یا بک‌اند در این نسخه وجود ندارد. پوسته و علاقه‌مندی‌ها در همان مرورگر ذخیره می‌شوند.

## آزمون‌های پایه

با نصب Node.js در پوشهٔ پروژه اجرا کنید:

```bash
node --check app.js
node --check data.js
node --check safety-data.js
node --check config.js
node --check sw.js
node tests/validate-data.js
```

این آزمون‌ها ساختار داده و کد را بررسی می‌کنند؛ فعال‌بودن همهٔ لینک‌ها، صحت جاری هر توصیه یا نصب/آفلاین‌بودن در همهٔ مرورگرها را تضمین نمی‌کنند.


## تایپوگرافی و آفلاین بودن فونت

فونت Vazirmatn variable از نشانی نسخه‌بندی‌شدهٔ jsDelivr دریافت می‌شود و Service Worker تلاش می‌کند آن را در زمان نصب cache کند. فایل WOFF2 به‌دلیل در دسترس نبودن فایل باینری در محیط ساخت، هنوز در بستهٔ ZIP محلی نیست؛ در بارگیری نخستِ آفلاین ممکن است فونت جایگزین دستگاه استفاده شود. این مورد از کارهای باقی‌مانده است. منبع اصلی و مجوز فونت در مخزن [Vazirmatn](https://github.com/rastikerdar/vazirmatn) قرار دارد.


## هویت بصری نسخهٔ ۰٫۶٫۰

- رویکرد طراحی: «راهنمای میدانی» به‌جای داشبورد عمومی؛ ترکیب پس‌زمینهٔ کاغذی و سبز جنگلی با تأکیدهای لیمویی و مرجانی.
- تایپوگرافی: Vazirmatn variable از CDN نسخه‌بندی‌شده و fallbackهای `Noto Sans Arabic` و `Tahoma`. بسته‌بندی مستقیم فایل WOFF2 هنوز انجام نشده است؛ بنابراین فونت اولیه کاملاً خودبسنده نیست.
- آیکون برنامه با نشان مستقل همراه و پالت سبز جنگلی، کرم، سبز برگ و مرجانی هماهنگ شده است. نسخه‌های SVG و PNG با نام‌های نسخه‌دار در `icons/` و favicon استاندارد در ریشه قرار دارند؛ Service Worker پوستهٔ نسخهٔ ۰٫۶٫۱ را جداگانه cache می‌کند.
- آزمون رگرسیون این بسته: `node --check` برای اسکریپت‌ها و `node tests/validate-data.js` برای ساختار داده‌ها و وجود آیکون‌های محلی. آزمون کامل تعاملی در همهٔ مرورگرها هنوز لازم است.


## معنی تاریخ بازبینی

`lastReviewed` تاریخ مرور و مرتب‌سازی داده‌ها در این نسخه است، نه تضمین فعال‌بودن همهٔ پیوندها. در ۲۵ اکتبر ۲۰۲۶ تعدادی از صفحات اصلی با مرورگر بررسی شدند، اما این کار آزمون قابل تکرار HTTP از چند شبکه یا بررسی امنیتی محسوب نمی‌شود و همهٔ URLها از نظر دسترس‌پذیری در همهٔ شبکه‌ها تضمین نشده‌اند. بازیطوری هنگام بازبینی پیام به‌روزرسانی نشان می‌داد؛ دسترس‌پذیری ندگرام و جزئیات Hoosha و Vasl از این بررسی به‌طور کافی تأیید نشدند. پیوندهای نیازمند بررسی با وضعیت احتیاطی مشخص شده‌اند. تاریخ/منبع راهنماهای ایمنی نیز منشأ ادغام‌شدهٔ محلی را ثبت می‌کند، نه تأیید مستقل پزشکی یا امدادی.
